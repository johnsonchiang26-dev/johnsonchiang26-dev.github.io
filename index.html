Thesis · SCIE

Knowledge-Driven Financial Time Series Forecasting

Quantified technical indicator knowledge — MA crossovers, KD zones, MACD slope — into engineered features. Multi-output models predict next-day OHLC changes. Knowledge features consistently outperformed raw price-volume data.

  • Developed a multi-output regression model (SVR, XGBoost, LSTM+Attention) to simultaneously predict next-day Open, High, Low, Close price changes — not just direction, but magnitude.
  • Transformed 158 raw technical indicators into "knowledge features" via arithmetic operations (e.g. MA5 − MA20, KD > 80), allowing models to learn indicator semantics rather than memorizing values.
  • Applied forward/backward feature selection to identify optimal subsets from 158 technical indicators, significantly improving prediction accuracy.
  • Integrated fuzzy logic systems to quantify expert linguistic terms (e.g. "high volume breakout", "golden cross") into numerical features, bridging domain knowledge with ML models.
  • Published as: Lee, C.H., Lee, T.J., Chiang, Y.S. et al. (2023). "Intelligent System for Stock Investment Decision Making." JISE, 39(5), 1101–1116. (SCIE indexed)

SMS & Email Anomaly Alerting Pipeline

End-to-end alerting system on AWS processing 90M+ SMS and 259M+ email records. 3-tier classification with historical baselines, incremental mode, and automated Lark notifications across 7 brands globally.

  • Designed a 3-tier alert classification (P75 / P90 / P95) using rolling 4-week historical baselines per brand × country × scenario, replacing manual thresholds with data-driven percentile rules.
  • Built incremental processing mode (--incremental --days 8) that reduced daily runtime from 13 minutes to 28 seconds by scanning only recent data instead of full-table recalculation.
  • Backfilled 92.6M + 31.2M detail rows for country_name and ip_country_name columns; discovered and fixed a scenario category leakage bug that was excluding ~40% of SMS records from the pipeline.
  • Investigated SMS fraud patterns — analyzed 1.1M verification requests, found 94% country mismatches, identified SMS Pumping attacks with Pakistan as the primary IP source.
  • Orchestrated via Airflow DAGs in Docker on AWS EC2. Alert results feed into Power BI dashboards for operations team monitoring across 7 brands and 16 SMS channels.
